This is a [Next.js](https://nextjs.org) app for the Welrent marketplace.

See the monorepo root [README](../README.md) for API + SDK setup, Act page wiring, screenshots, and public GitHub proof.

## Getting Started

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Important routes: `/`, `/act`, `/offerlist`, `/vehicle/[slug]`, `/locations`.
